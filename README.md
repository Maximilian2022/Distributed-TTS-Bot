# Discord TTS Bot

自然な日本語音声でテキストチャットを読み上げる、低遅延設計のDiscord読み上げBotです。

個人利用の小規模サーバーから、複数VC（ボイスチャンネル）が同時に稼働するコミュニティまで、安定してスムーズな読み上げ環境を提供します。

---

## 主な機能

- **高音質・超低遅延の音声合成**
  - 音声ストリーミング処理と先読み・並列合成により、発言から再生開始までの待機時間を最小限に抑制しています。
  - 句読点によるスマート分割と自然な無音ギャップ挿入により、滑らかで聞き取りやすい読み上げを実現します。

- **多様な音声エンジン対応（Edge-TTS ファースト）**
  - **初期設定不要**: 高度なAPIキーやGPU環境を用意しなくても、無料の Edge-TTS（または OpenJTalk）ですぐに動作します。
  - **クラウド連携**: Azure AI Speech や Google Cloud Text-to-Speech のAPIキーを登録することで、さらに表現力豊かな音声へ拡張できます。
  - **ローカル・分散音声エンジン**: VOICEVOX、SHAREVOX、COEIROINK に対応。同一マシン内のローカル実行はもちろん、別PC（GPU搭載機など）をWorkerノードとして接続し、負荷を分散できます。

- **多重フェイルオーバー**
  - 優先エンジンにネットワーク障害やレート制限が発生した場合でも、自動的に代替エンジン（Edge-TTS / OpenJTalk 等）へ瞬時にフォールバックし、通話を中断させません。

- **WebUIによる直感的な管理**
  - ブラウザからギルドごとの読み上げ設定、ユーザー辞書、Botの稼働状況を確認・変更できます。
  - システム管理者向けに、APIキーの設定やDiscord Botトークンの動的プール管理（追加・停止）機能を提供します。

- **動的Botプール（複数号機スケール）**
  - 同一サーバー内で複数のボイスチャンネルが同時に使用されている場合でも、空いている別号機Botが自律的に参加し、1つのBotアカウントの接続制限を回避して並行読み上げを行います。

- **辞書・読み替え機能**
  - サーバー共通の単語辞書、ユーザーごとの個別辞書、正規表現パターンによるURLや絵文字の自動省略に対応しています。

---

## 構成要件

- **Docker / Docker Compose** が利用可能な環境（Linux / macOS / Windows WSL2）
- **Discord Bot Token**（Discord Developer Portalより取得）
- メモリ: 1GB以上（ローカルVOICEVOXを同梱する場合は 4GB以上推奨）

## クイックスタート

### 1. リポジトリのクローンと準備

```bash
git clone https://github.com/your-username/ttsbot.git
cd ttsbot

# 設定テンプレートをコピー
cp .env.example .env
```

### 2. 環境変数の設定

`.env` を任意のエディタで開き、必要な項目を設定します。
（BotトークンやAPIキーは、起動後にWebUIから設定することも可能です）

```ini
# Discord Bot Token（WebUIから登録する場合は空のままでも起動可能）
DISCORD_TOKEN=your_bot_token_here

# WebUI管理者のログインパスワード
ADMIN_PASSWORD=your_secure_password
```

### 3. コンテナの起動

```bash
docker compose up -d
```

起動後、ブラウザで `http://localhost:8080`（またはサーバーのIPアドレス）にアクセスすると管理画面が開きます。

## 使い方

1. **ボイスチャンネルへの呼び出し**
   - 参加したいボイスチャンネルに入室した状態で、テキストチャンネルで `/join` コマンドを入力します。
2. **読み上げ**
   - 紐付けられたテキストチャンネルにメッセージを投稿すると、Botが自動的に音声を合成して読み上げます。
3. **ボイスチャンネルからの退出**
   - `/leave` コマンドを入力すると、Botが通話から退出します。
4. **声色・速度の変更**
   - `/voice` コマンドで利用可能な声の一覧表示や、自身の声色・速度・ピッチのカスタマイズが可能です。
