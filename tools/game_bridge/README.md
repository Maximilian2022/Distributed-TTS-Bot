# Hayamimi Game Bridge (ゲームチャット自動入力ツール)

Discord VC で自分が喋った音声を、早耳 Live (Hayamimi) を通じてリアルタイムに文字起こしし、
ゲーム内のテキストチャット入力欄へ自動的に貼り付けて Enter 送信する Windows 用クライアントです。

---

## 🚀 使い方

1. **`run.bat` をダブルクリックして実行するだけ！**
   - 初回起動時に `uv`（Python マネージャー）および必要なライブラリが自動セットアップされます。
   - 2回目以降の起動時にも、GitHub / TTSBot サーバーから最新版へ自動更新されます。
2. 初回起動時、対話画面で以下を入力します：
   - **TTSBot の サーバー URL**（例: `ws://192.168.11.244:8088`）
   - **あなたの Discord ユーザー ID**（自分の発言だけを入力させるため推奨）
3. ゲームを起動し、テキストチャットの入力欄にカーソルを合わせてアクティブにしておきます。
4. Discord VC で喋ると、確定した瞬間に自動で `Ctrl+V ➔ Enter` が入力されます。

---

## 🛡️ セーフティ機能
- **緊急停止**: マウスカーソルを画面の左上隅（座標 0, 0）に勢いよく動かすと即座に強制終了します（pyautogui failsafe）。
- **IME 誤変換防止**: 1文字ずつのタイピングではなく「クリップボード貼り付け」方式を採用しているため、全角/半角 IME による誤変換や文字欠けが一切起きません。
